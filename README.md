# 北医下班宇宙

一个从北医博士的实验日常出发，也陪医生和老师松口气的非官方解压小玩具。

**[进入下班宇宙，开始解压 →](https://chymlltrn.github.io/beiyi-after-hours/)**

## 选一个今天的自己

- **博士生**：把实验仪器甩飞，让「再补一组」变成纸屑；炸开挤满 DDL 的地球，再和鼠鼠踩拍子。
- **医生**：给文书盖一枚虚构交班章，让纸页飞散；暂停工作通知，拆开排班时钟，再去茶歇小岛坐坐。
- **老师**：把作业折成纸鹤、擦掉黑板上的拥挤；收起教学通知，炸开表格星球，让下课铃带你去花园。

三类身份各有四个场景，共十二套道具、通知、回应和结局。切换身份会收拾当前场景，随时重新开始。

拖动、点击或按键都可以玩；按住星球或时钟约 2.4 秒，松手释放蓄力。普通动效下，大招持续约 2.6 秒，呈现轮廓碎裂、冲击波、纸页或碎片飞散与余波；系统「减少动态效果」设置下保留静态碎裂反馈。支持连击、三种解压强度、沉浸模式和无限重玩；结局保留在画布上，庆祝窗口由用户主动打开。

还有文字碎纸机、一分钟呼吸和一张给自己的休息许可。吐槽只在当前页面内存中处理，清空后不留历史，没有后端与数据上传；呼吸练习可以随时结束，页面切到后台会暂停计时。身份选择也不写入浏览器存储。

所有角色和场景均为虚构，与北京大学或北京大学医学部无官方关联。鼠鼠们全员平安下班。

## 本地运行

需要 Node.js 18 或以上，无需安装依赖。

```sh
npm run dev
```

打开 `http://127.0.0.1:8087`。`PORT=8090 npm run dev` 可以更换端口。

```sh
npm run check
npm run build
```

仓库根目录可直接部署到 GitHub Pages；`dist/index.html` 是把样式、绘图、脚本全部嵌入的离线单文件，双击也能玩。资源均使用相对路径，支持 GitHub 项目子目录。

## 交互与可访问性

桌面和手机均可使用；互动画布支持拖动、点击、触摸、空格和回车。星球与时钟模式按住空格/回车可蓄力，其余场景按键即可操作。默认静音，开启后各模式音效与爆破余声由 Web Audio 合成。自动遵循系统「减少动态效果」设置，后台标签页暂停 Canvas 动画。Escape 退出沉浸模式与庆祝窗口。

原创 Canvas 插画、原生 JavaScript 和 CSS，无外部字体、图片、追踪器或第三方运行依赖。

## 浏览器验证

`qa/browser-check.cjs` 使用外部提供的 Playwright 检查三类身份的十二套玩法、角色切换、手机触摸、七种视口宽度、音效、碎纸机输入与呼吸计时。运行环境提供 Playwright 与浏览器后可执行：

```sh
node qa/browser-check.cjs
```

可选环境变量：`PLAYWRIGHT_PATH` 指定 Playwright 模块，`CHROME_PATH` 指定浏览器，`SITE_URL` 指定测试网址，`BROWSER_PROXY` 指定浏览器代理。`qa/verification.json` 和 `qa/visual-verdict.json` 保留检查结果。
