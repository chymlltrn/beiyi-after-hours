# 北医下班宇宙

一个从北医博士的实验日常出发，也陪医生和老师松口气的非官方解压小玩具。三种身份会进入实验室、医院、学校，使用各自的道具和玩法。

**[进入下班宇宙，开始解压 →](https://chymlltrn.github.io/beiyi-after-hours/)**

## 选一个今天的自己

- **博士生 · 实验室**：甩开实验仪器，把导师群消息揉成纸屑，炸开实验室墙前的 DDL 球。鼠鼠可以逐只点按，会转圈、冒泡泡、接零食；实验台旁也有博士生和鼠鼠。
- **医生 · 医院**：把六份标书、检查与 DRG 文书拖进三只分类箱，暂停行政通知，蓄力炸开 DRG 纸堆，再逐件收走行政传送带上的任务。
- **老师 · 学校**：先点按或拖动桌上的额外任务，把报表与材料揉成纸团投回漫画人物；再将额外通知揉团或折成纸飞机，同样投回并贴上通知条。教室里的漫画人物参考用户提供的照片制作，还能蓄力或连续投出非教学报表、迎检材料、打卡截图、临时会议、重复录入、家校群与评比台账；纸团会夸张地弹开，任务变成贴条和彩纸。

三类身份各有四个场景，共十二套道具、通知、回应和结局。拖甩、归箱、投纸团、喂鼠鼠和传送带操作分别对应不同场景；切换身份会收拾当前场景，随时重新开始。

拖动、点击或按键都可以玩；按住 DDL 球、DRG 纸堆或老师场景的漫画人物约 2.4 秒，松手释放蓄力。普通动效下，大招持续约 2.6 秒：仪器和 DDL 球碎裂，DRG 文书炸成纸雨，老师场景呈现纸团弹开与贴条和彩纸，漫画人物保持完整。系统「减少动态效果」设置下保留静态反馈。支持连击、三种解压强度、沉浸模式和无限重玩；结局保留在画布上，庆祝窗口由用户主动打开。

还有文字碎纸机、一分钟呼吸和一张给自己的休息许可。吐槽只在当前页面内存中处理，清空后不留历史，没有后端与数据上传；呼吸练习可以随时结束，页面切到后台会暂停计时。身份选择也不写入浏览器存储。

互动与台词是解压场景的创作，照片参考仅用于漫画形象，没有推断人物身份或添加真实人物事迹。网站与北京大学或北京大学医学部无官方关联。鼠鼠们全员平安下班。

## 本地运行

需要 Node.js 18 或以上，无需安装依赖。

```sh
npm run dev
```

打开 `http://127.0.0.1:8087`。`PORT=8090 npm run dev` 可以更换端口。

```sh
npm run check
npm run build
```

仓库根目录可直接部署到 GitHub Pages；`dist/index.html` 是把样式、绘图、脚本和漫画人物素材全部嵌入的离线单文件，双击也能玩。资源均使用相对路径，支持 GitHub 项目子目录。

## 交互与可访问性

桌面和手机均可使用；互动画布支持拖动、点击、触摸、空格和回车。第三个场景按住空格/回车可蓄力，其余场景按键即可操作；医生分类箱也保留点按操作入口。默认静音，开启后各模式音效与爆破余声由 Web Audio 合成。自动遵循系统「减少动态效果」设置，后台标签页暂停 Canvas 动画。Escape 退出沉浸模式与庆祝窗口。

原创 Canvas 插画、用户照片参考生成的本地漫画素材、原生 JavaScript 和 CSS。无外部字体、追踪器或第三方运行依赖。

## 浏览器验证

`qa/browser-check.cjs` 使用外部提供的 Playwright 检查三类身份的十二套玩法、背景差异、分类归箱、鼠鼠回应、任务投递、角色切换、手机触摸、七种视口宽度、音效、碎纸机输入与呼吸计时。运行环境提供 Playwright 与浏览器后可执行：

```sh
node qa/browser-check.cjs
```

可选环境变量：`PLAYWRIGHT_PATH` 指定 Playwright 模块，`CHROME_PATH` 指定浏览器，`SITE_URL` 指定测试网址，`BROWSER_PROXY` 指定浏览器代理。`qa/verification.json` 和 `qa/visual-verdict.json` 保留检查结果。
